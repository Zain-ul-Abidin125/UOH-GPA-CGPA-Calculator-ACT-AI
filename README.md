# 🎓 UOH Smart GPA Advisor

An AI-powered GPA & CGPA Calculator built specifically for **University of Haripur (UOH)** students.

This web application helps students accurately calculate their **Semester GPA** and **Overall CGPA** using the official UOH grading criteria. Unlike traditional GPA calculators, it also includes an intelligent **AI Academic Advisor** that can understand natural language, modify academic records, recalculate results instantly, answer academic questions, and help students plan their academic progress.

---

# 📌 Problem Statement

Many students calculate their GPA manually or use generic GPA calculators that:

- Do not follow the University of Haripur grading system.
- Cannot calculate CGPA correctly across semesters.
- Require manual editing of marks and subjects.
- Cannot answer academic questions or predict future GPA.

This project solves these problems by providing a modern AI-powered academic assistant designed specifically for UOH students.

---

# 👨‍🎓 Target Users

- University of Haripur (UOH) students
- Students who want quick GPA and CGPA calculations
- Students who need help managing their academic record
- Students who want AI assistance for academic planning

# ✨ Features

## 📊 GPA Calculator
- Calculate Semester GPA
- Automatic Grade Point calculation
- Uses official UOH grading criteria
- Instant results

## 🎓 CGPA Calculator
- Calculate Overall CGPA
- Combine multiple semesters
- Automatic updates after any changes

## 🤖 AI Academic Advisor

The AI Advisor can understand natural language and manage the academic record automatically.

It can:

- Change subject marks
- Update Semester GPA
- Update Overall CGPA
- Add new subjects
- Delete subjects
- Rename subjects
- Modify semesters
- Correct academic records
- Predict future GPA
- Predict future CGPA
- Explain GPA calculations
- Answer academic questions
- Recalculate everything instantly after every change

Example commands:

- Change my Semester 3 GPA from 2.70 to 3.10
- Change Kinesiology I marks from 75 to 83
- Delete Pakistan Studies from Semester 2
- Add Artificial Intelligence with 3 Credit Hours and 88 marks to Semester 6
- What will my CGPA become if I score 90 in Machine Learning?

The AI automatically identifies the correct semester, subject, and updates all GPA and CGPA calculations without requiring manual edits.

---

# 🧠 AI Feature

The application includes an AI Academic Advisor powered by Google's Gemini model.

## AI Responsibilities

The AI has permission to:

- Read academic records
- Edit subjects
- Update marks
- Add or remove subjects
- Modify semester data
- Recalculate GPA
- Recalculate CGPA
- Answer academic questions
- Predict academic outcomes

The AI acts as an academic assistant that manages the application's data through natural language.

## AI System Prompt (Summary)

The AI is instructed to:

- Act as an academic advisor for University of Haripur students.
- Follow the official UOH grading policy.
- Understand natural language requests.
- Automatically determine the correct semester for known subjects.
- Update marks, GPA, and CGPA whenever academic data changes.
- Add, delete, rename, or modify subjects when requested.
- Never require unnecessary manual input if the information can be inferred from existing academic records.
- Always recalculate GPA and CGPA after any modification.

# 🚀 How to Run the Project

## 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

## 2. Open the project folder

```bash
cd YOUR_REPOSITORY
```

## 3. Add your Gemini API Key

Create a `.env` file (or configure the API key as required by your project) and add:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

## 4. Start the application

Run the project using your preferred local development server and open it in your browser.
